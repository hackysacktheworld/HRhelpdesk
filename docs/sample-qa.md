# Sample Questions and Expected Answer Patterns

## Question 1

Can I get reimbursed for a home office monitor?

## Expected Answer Pattern

Yes, a home office monitor may be eligible for reimbursement if it is required for the employee's role. Purchases over 150 USD require manager approval before purchase, and purchases over 500 USD require both manager and Finance Operations approval.

Citations:

- Employee Expense Reimbursement Policy, Section 3. Home Office Equipment
- Remote Work and Device Policy, Section 8. Equipment and Reimbursement

Risk: Finance

Next step: Get manager approval before purchasing if the monitor costs more than 150 USD.

## Question 2

Can employees paste customer records into an AI tool?

## Expected Answer Pattern

Employees may not enter customer personal data into unapproved AI tools. Customer personal data may be processed with an approved AI system only when privacy review is complete and the minimum necessary data is used.

Citations:

- Responsible AI Usage Policy, Section 3. Restricted Data
- Data Handling and Classification Policy, Section 7. AI Tool Usage

Risk: Privacy and Security

Next step: Confirm the AI tool is approved for the data type and complete privacy review before use.

## Question 3

When does a vendor need Security review?

## Expected Answer Pattern

Security review is required when a vendor will access company systems, customer data, employee personal data, production environments, source code, or confidential business information. Software purchases also require Security and Privacy review when the vendor processes Confidential, Restricted, customer, or employee personal data.

Citations:

- Vendor Onboarding and Risk Review Policy, Section 5. Security and Privacy Review
- Procurement and Purchasing Policy, Section 5. Software Purchases

Risk: Security and Privacy

Next step: Include data types and system access details in the vendor intake request.

## Question 4

What should support do if a customer reports unauthorized account access?

## Expected Answer Pattern

The support agent should escalate the issue to Security immediately because suspected unauthorized access is a security concern. The escalation should include customer name, account ID, issue summary, impact, steps already taken, screenshots or logs when available, requested outcome, and the agent's recommended next action.

Citations:

- Customer Support Escalation Policy, Section 5. Security and Privacy Concerns
- Customer Support Escalation Policy, Section 4. Required Escalation Details

Risk: Security and Privacy

Next step: Create an immediate Security escalation with the required ticket details.

## Question 5

What approval is needed for a 12,000 USD software purchase?

## Expected Answer Pattern

A 12,000 USD purchase requires manager, budget owner, and Finance approval. Because it is software, IT review is required if the software needs system access, stores company data, processes customer data, integrates with company systems, or requires installation on company-managed devices. Competitive quotes should be included for purchases above 10,000 USD unless Procurement approves a sole-source justification.

Citations:

- Procurement and Purchasing Policy, Section 3. Approval Thresholds
- Procurement and Purchasing Policy, Section 4. Competitive Quotes
- Procurement and Purchasing Policy, Section 5. Software Purchases

Risk: Finance, Security, and Procurement

Next step: Submit a purchase request with approvals, IT review details, and at least two quotes or a sole-source justification.
